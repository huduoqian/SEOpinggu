# SEOpinggu 🔍

> 轻量级 SEO 内容质量评估工具 —— 输入网址，一键获取优化建议。

## ✨ 特性

- 📈 **综合评分**：加权计算 8 大维度，输出 0~100 健康分
- 🔑 **关键词分析**：密度检测 + 位置检查（标题/描述/正文）
- 📝 **可读性评估**：Flesch Reading Ease 指数
- 🧱 **结构审计**：H1~H3 层级、图片 Alt、内/外链统计
- 🚀 **开箱即用**：支持 URL 抓取或本地 HTML 文件

## 🛠 安装

git clone https://github.com/huduoqian/SEOpinggu.git
